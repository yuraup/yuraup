## What I usually care about 💡
Here are the areas I'm currently focusing on as I grow as a frontend developer:

#### 1. User Experience
I believe that a great UI starts with a well-structured design.  
To understand this better, I’ve been practicing by creating my own Figma designs.  
And I've applying atomic design principles to improve consistency and scalability.

#### 2. Performance Optimization
I'm learning how to make web services faster and smoother  
by studying rendering behavior and trying to reduce unnecessary re-renders.

#### 3. Business-Oriented Thinking
When I build a project, I try to think beyond just the code.  
I remind myself of the product’s purpose and user needs so I can make more meaningful features.
